# Reproducibility release v0.1.0

This distribution contains the 12 recovered Python source scripts for the manuscript **A Topological Selected-Solve Approximation of Inverse Hodge Operators for Explicit DEC/FETD Maxwell Simulations**.

* Algorithms and original numeric outputs have not been modified by this packaging step.
* BSD-3-Clause applies to source code in `scripts/`.
* Archived numeric outputs and the figure files are published as a separate dataset.
* No journal article DOI is assigned or asserted at the time of preparation.
